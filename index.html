📄 Chat Export Tool

ChatGPT / Claude / Gemini の公開チャットをPDF化

🚀 使い方（3ステップ）

  1. Bookmarkletを取得
    下のボタンをクリックしてブックマークレットをクリップボードにコピーします。
  2. ブックマークに登録
    ブラウザのブックマークバーに新しいブックマークを作成し、URLにコピーしたコードを貼り付けます。
  3. 共有ページで実行
    ChatGPT/Claude/Geminiの公開共有リンクを開き、登録したブックマークをクリックします。

クリック後、ブラウザのブックマークマネージャーで新規ブックマークを作成し、
URLフィールドに貼り付けてください。

✅ 対応プラットフォーム

ChatGPT
chatgpt.com/share/*
Claude
claude.ai/share/*
Gemini
gemini.google.com/share/*
📌 重要: 完全公開されている共有リンクのみ対応しています。ログインが必要なページや、認証トークンが必要なページでは動作しません。

⚙️ 機能

  • ワンクリック起動: ブックマークをクリックするだけで自動的に全処理が実行されます
  • 進捗表示: 右上に処理状況をリアルタイム表示（スクロール→展開→抽出→生成）
  • 自動スクロール: 仮想スクロールに対応し、すべてのメッセージを自動読み込み
  • 自動展開: 「もっと見る」ボタンを自動クリックして長文を完全表示
  • 賢い抽出: 複数のセレクタ戦略でユーザーとAIのメッセージを正確に識別
  • 整形表示: グラデーション背景でユーザーとAIを視覚的に区別
  • 印刷最適化: 改ページ制御でメッセージが途中で分割されないレイアウト
  • コード保持: 等幅フォントと言語タグでコードブロックを美しく表示
  • 完全ローカル: データは外部に送信されず、すべてブラウザ内で処理

📖 詳細手順

1. Bookmarkletのコピー

上の「📋 Bookmarklet をコピー」ボタンをクリックすると、自動的にクリップボードにコピーされます。

2. ブックマークへの登録方法

Chrome / Edge:

  1. ブックマークバーを表示（Ctrl+Shift+B / Cmd+Shift+B）
  2. ブックマークバーの空白部分を右クリック → 「ページを追加」
  3. 名前: Export Chat
  4. URL: コピーしたコードを貼り付け
  5. 保存

Firefox:

  1. ブックマークバーを表示（Ctrl+Shift+B / Cmd+Shift+B）
  2. ブックマークバーを右クリック → 「新しいブックマーク」
  3. 名前: Export Chat
  4. URL: コピーしたコードを貼り付け
  5. 保存

3. 使用方法

  1. ChatGPT/Claude/Geminiの公開共有リンクをブラウザで開く
  2. ページが完全に読み込まれるまで待つ
  3. ブックマークバーの「Export Chat」をクリック
  4. 自動的に処理が開始され、右上に進捗が表示されます
  5. 完了すると新しいタブに整形ページが自動で開きます
  6. ブラウザの印刷機能（Ctrl+P / Cmd+P）でPDF保存

🔒 セキュリティとプライバシー

✓ 完全ローカル処理: すべての処理はブラウザ内で完結します。会話データは外部サーバーに送信されません。
  • ネットワークリクエストは一切発生しません
  • 抽出データはメモリ上でのみ処理され、保存されません
  • オープンソースコード（このページのソース参照可能）
  • 外部ライブラリへの依存なし（Vanilla JavaScript）

⚠️ 既知の制限

以下の制限事項をご理解の上ご使用ください。
  • サイトUI変更: ChatGPT/Claude/Gemini側のUI変更により、将来的に動作しなくなる可能性があります
  • 仮想スクロール: 自動スクロールを有効にしないと、画面外のメッセージが取得できない場合があります
  • 画像の制限: クロスオリジン制限により、一部の画像は取得できない場合があります
  • リッチコンテンツ: 特殊なウィジェットやインタラクティブ要素は完全再現できません
  • 無効なリンク: 共有リンクが削除・無効化されている場合は取得できません
  • 認証必須ページ: ログインが必要なページでは動作しません

🔧 トラブルシューティング

Q: 一部のメッセージが抽出されない

A: 「自動スクロールして全文ロード」オプションを有効にしてください。ページを最後までスクロールしないと、仮想スクロールにより一部のメッセージがDOM上に存在しない場合があります。

Q: 長文が途中で切れている

A: 「折りたたみを展開」オプションを有効にしてください。「もっと見る」ボタンが自動的にクリックされます。

Q: エラーが表示される

A: 以下を確認してください:

  • 正しい共有ページ（ChatGPT/Claude/Gemini）で実行しているか
  • ページが完全に読み込まれているか
  • ブラウザの JavaScript が有効になっているか

Q: PDF化するとレイアウトが崩れる

A: ブラウザの印刷設定で「背景のグラフィック」を有効にしてください。また、余白設定を調整することで改善する場合があります。
